# Investigation sweep plans

**Read-only output** from [Investigation LLM sweep](../INVESTIGATION_LLM_SWEEP.md) runs.

Each file is a **plan**, not a committed investigation edit. The author reviews, accepts or rejects items, then implements changes manually or in a separate agent session.

**Git:** Generated `*-sweep-plan.md` files are **gitignored** — they stay on your machine for review. Only this README and the template are tracked.

**Naming:** `YYYY-MM-DD-{investigation-slug}-sweep-plan.md`

**Template:** [`_TEMPLATE_SWEEP_PLAN.md`](_TEMPLATE_SWEEP_PLAN.md)
