# Magic as operator technology — lexical rule

**Purpose:** Canonical definition of **magic** in Paradigm Threat investigations and reader-facing articles. Pair with [**prisca sapientia**](PRISCA_SAPIENTIA.md) (ancients held profound understanding; later systems degraded it) and [**REDACTION.md**](REDACTION.md) (how knowledge was misfiled in public narrative).

---

## Definition

In this corpus, **magic** means **misfiled operator technology** — procedures and hardware that produce effects **demonstrable in nature** or **reproducible in a lab**, mislabeled as supernatural, folk belief, or religious miracle after institutional redaction.

**Magic is not supported** as a separate metaphysical category. If a claimed effect cannot map to a **demonstrable phenomenon** (physical substrate, measurable coupling, reproducible protocol), the corpus **does not endorse it**.

---

## What counts (examples)

| Public / historical label | Repo read — demonstrable class |
|---------------------------|--------------------------------|
| Seer stone, scrying | Locate / couple interface; altered-state resonance read |
| Magic circle + consecrated blade | Operator boundary; geometric safety protocol during breach |
| Planetary sigils + divine names on metal | Protocol ID + authentication strings on hardware |
| Treasure-guardian apparitions | Breach coupling phenomenology; embedded analog memory release |
| Gold plates, crystal memory | Analog index; extreme-resolution signal storage in medium |
| Cargo-cult ritual, manna obedience | Degraded imprint of earlier delivery / rehab tech |

Mechanisms may be **partially lost** or **misdescribed** in grimoires and folklore. The claim is not that every medieval operator understood physics — but that the **effects belong to nature**, not to a supernatural exception class.

---

## What is excluded

- Supernatural causation without physical substrate
- Unbounded “energy” or “vibration” that cannot in principle be tested
- Wish-based outcomes with no operator, medium, or protocol
- Effects that **cannot** be demonstrated in nature or lab even in principle

When primary sources use *spirits*, *angels*, or *devils*, quote verbatim; gloss as **coupling phenomenology**, **embedded memory release**, or **historical operator vocabulary** — not endorsement of undemonstrable entities unless a separate tiered claim is explicitly made.

---

## Usage in prose

1. **Quote** historical and scholarly *magic* language verbatim when it is the source (affidavits, Ashurst-McGee, Barrett).
2. **Gloss once** in repo voice: **operator protocol**, **keeper hardware**, **redacted engineering**.
3. Prefer **operator technology**, **keeper protocol**, **coupling**, **analog index** in running argument.
4. **Folk magic** in article voice → **folk-magic label** or **what textbooks call magic** when describing embarrassment/containment frames.
