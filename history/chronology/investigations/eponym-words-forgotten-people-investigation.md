## 1. Author thesis — person → word → rebrand → forget

When establishment history **rewrote** the Rus–Horde and Crusade layers, **personal names** in oral memory could:

1. **Crystallize** into **nouns**, **surnames**, or **place-names**
2. **Detach** from the **forgotten event** via **Protestant / Latin** spelling drift (**Lane A**)
3. **Re-attach** to a **modern celebrity**, **brand**, or **commodity** (actor, food company, city) — **oscillating** public memory
4. **Seal** under **handbook etymology** (“from Old French…”, “from Germanic…”) with **no person** in the chain

**Not claimed:** every word is an eponym; every celebrity name is a redaction. This is a **search lane** for **high-suspicion** tokens the author flags.

## 3. Research protocol (per candidate)

1. **Earliest English attestations** (OED, EEBO, COHA) — noun vs name vs place
2. **Event candidate** on PT timeline — link **evt-** if plausible
3. **Rebrand event** — film, brand, celebrity peak (documented press dates)
4. **Handbook line** — paste mainstream etymology in **contrast** block
5. **Verdict** — `refuted` / `open` / `author-plausible` / `documented eponym`
