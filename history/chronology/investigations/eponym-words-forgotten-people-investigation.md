## 1. Author thesis — person → word → rebrand → forget

When establishment history **rewrote** the Rus–Horde and Crusade layers, **personal names** in oral memory could:

1. **Crystallize** into **nouns**, **surnames**, or **place-names**
2. **Detach** from the **forgotten event** via **Protestant / Latin** spelling drift (**Lane A**)
3. **Re-attach** to a **modern celebrity**, **brand**, or **commodity** (actor, food company, city) — **oscillating** public memory  
4. **Toxic-name whitewash (author):** vilified **historical** bearer of a name → **beloved modern celebrity** with the **same** surname or given name — establishment **re-popularizes** the token so the old charge cannot stick (flagship: **Francis Bacon** → **Kevin Bacon**; see §2c)  
5. **Seal** under **handbook etymology** (“from Old French…”, “from Germanic…”) with **no person** in the chain

**Not claimed:** every word is an eponym; every celebrity name is a redaction. This is a **search lane** for **high-suspicion** tokens the author flags.

### §2c — Toxic-name celebrity whitewash (author, 2026-06-27)

> **Author:** Some names were **hated in the redaction era** — readers knew **what** the bearer was doing to scripture, empire, or memory — then a **modern celebrity** with the **same name** arrives and the establishment **re-popularizes** the token. Folk guilt **cannot attach** to **Kevin Bacon** the way it attached to **Francis Bacon** the redactor; the surname is **scrubbed by likability**.

**Pattern (search lane):**

| Step | Mechanism |
|------|-----------|
| 1 | Historical figure tied to **mass print / Bible / chronology seal** → **villain** in oral memory |
| 2 | Name also exists as **common noun** or **homophone** (pork *bacon*, traitor *judas*) — Lane B blur |
| 3 | **Celebrity** with same name peaks in **film / music / meme** culture → **positive** affect replaces **negative** |
| 4 | Handbook + media treat names as **unrelated** homonyms |
