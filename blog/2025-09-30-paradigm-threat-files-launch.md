# September 2025: paradigm-threat-files Repository Created

*September 30, 2025 — Paradigm Threat*

---

Retrospective: the paradigm-threat-files repository was initialized on **September 30, 2025** with its initial commit.

---

## What paradigm-threat-files Would Become

This repository would grow into the **investigations and content library** for the Paradigm Threat project — governance research, cosmology articles, influence studies, stolen credit investigations, predictive programming catalogs, and the blog you're reading now.

The separation of files from the main site allowed:

- **Static deployment** to GitHub Pages for fast, CDN-served content
- **Independent versioning** of investigations from site code
- **Structured index** for the DynamicNav and file browser
- **Cross-repo linking** between timeline events and investigation evidence

---

## Context

paradigm-threat-site (the main web presence) had been live since October 2023. The files repo was the next step in decoupling content from application code, preparing for the timeline project that would launch in early 2026.
