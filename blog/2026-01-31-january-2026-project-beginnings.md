# January 2026: Timeline Project Begins, paradigm-threat-files Refactor

*January 31, 2026 — Paradigm Threat*

---

Retrospective summary of project activity leading up to the February timeline launch.

## paradigm-threat-timeline

The timeline repository was created on **January 31, 2026** with the first commit. Initial work included:

- **Hierarchy refactor** — Event structure and article organization
- **Content structure** — Articles by section; before-creation media; 3 plasmoids image
- **Events and index** — Initial events.json and index updates

## paradigm-threat-files

Significant refactoring throughout January:

- **January 15** — Major restructure
- **January 25** — Refactor PopImage components to standard Markdown images
- **January 26** — Index.json with tree structure, _count, _title, and _lqip metadata; GitHub Actions for static deployment; forgotten-future page and assets; CleverTree projects; Relay URL update; logo and image updates
- **January 31** — History/chronology page update

## paradigm-threat-site

The main site at [paradigmthreat.net](https://paradigmthreat.net) continued to serve content. The timeline component would integrate in February.

---

## What This Built Toward

The January work established the timeline's data model, the files repo's structure for investigations and static deployment, and prepared the foundation for the **February 22 timeline launch** — the dedicated interactive chronology that would bring Scaligerian, Fomenko, Saturnian, and indigenous dates into a single navigable database.
