# October 2023: Paradigm Threat Site Launches

*October 31, 2023 — Paradigm Threat*

---

Retrospective: the Paradigm Threat web presence began with the initial commit to paradigm-threat-site on **October 9, 2023**.

---

## What Launched

The first version of the site included:

- **Next.js application** — Dynamic routing, layout, and styling
- **Search** — File search and search API (with subsequent fixes for form, styles, and crashes)
- **Cypress** — E2E testing and deploy workflow
- **Embed support** — PDF, WebM, and other file embeds (later refined as EmbedFile)
- **Navigation** — Dynamic nav and floating nav components
- **Image handling** — PopImage component for responsive images

---

## Early Iterations

Throughout October and November 2023, the team addressed:

- Blur and layout fixes
- Search API and form behavior
- CSS refinement for image searches
- Text and embed handling in search results
- Auto-generation script updates
- Zod validation

---

## The Foundation

This launch established paradigmthreat.net as the home for the project's research — a place where investigations, chronology cross-references, and alternative history could be published and navigated. The timeline component, paradigm-threat-files repository, and dedicated event database would build on this foundation over the next two years.
