## 1. Method — not all-or-nothing

| Bucket | What goes here | How used |
|--------|----------------|----------|
| **D — Documented specimen** | Named county + named race + published outlet/SOS with counts or procedure failure | Builds the anomaly list |
| **F — Media / official frame** | “Human error,” “USPS,” “nothing wrong with ballots,” “results unchanged” | Recorded; not automatic exoneration |
| **R — Rumor / tainted meme** | Viral claims with a **debunkable bait** plus optional real signal | Packet: kill bait, keep signal ([§7](#7-tainted-memes--poison-nodes)) |
| **K — Debunk / fact-check** | Corrects a specific false claim | Does **not** close the specimen bucket or the whole file |

**Rule:** A successfully framed “human error” story is still a **specimen** if votes were missing, late, flipped, or recovered after the public night total. Competence excuses are **F**, not proof the channel cannot be abused.

**Rule (author — registration = fraud for this file):** Do **not** treat illegal/ineligible registration, noncitizen rolls, household/proxy voting, or multi-decade immigrant-constituency construction as a softer category than “classic” ballot fraud. **Same investigation bucket.** Stealing a count on election night and **building a constituency that should not be eligible to vote** (or that votes through family/proxy patterns) are both **election theft in real time** — one fast, one slow. Lawyers and press split them to make fraud “hard to claim”; this file does **not**. Mechanism language can note *how* (USB vs roll vs border policy); verdict language does **not** exonerate the slow path.

**Rule:** This file does **not** conclude “the midterms were stolen” as a finished forensic finding. It concludes whether the **published record** already contains enough operational weirdness — **including roll/eligibility construction** — that a non-activist reader should demand **government-grade resolution** (logs, cards, **rolls**, cameras, citizenship audits) — not meme wars.
