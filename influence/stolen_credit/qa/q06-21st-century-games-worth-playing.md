# Q6 — Which 21st-century games are still worth playing?

**Question:** Which 21st-century games does this reading still call worth playing?

## Answer

The personal list is short. *Half-Life 2.* *Metroid Prime* 1 only, Switch HD as the playable copy. *Donkey Kong Country Returns*, Switch version only, after a fourteen-year wait. *Tropical Freeze.* *Star Fox Zero* if you have a Wii U. A few more might be added later. The rest of the century is treated as compromise product: social lectures, no real heroes, leadership framed as something the majority should suppress.

That is taste plus a warning, not a census of every disc. It lives in [Before Barney, Teletubbies, and Pokémon](/influence/stolen_credit/before-barney-and-pokemon.md).
